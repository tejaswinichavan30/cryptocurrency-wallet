# 💰 Cryptocurrency Wallet

A secure web-based cryptocurrency wallet application that allows users to create an account, securely manage wallet balances, send and receive cryptocurrency, and view transaction history through an intuitive web interface.

---

## 🚀 Live Demo

🔗 **Application:** [Cryptocurrency Wallet](https://cryptocurrency-wallet-zrzq.onrender.com)

---

## ✨ Features

- 🔐 User authentication (Sign Up & Login)
- 👛 Secure cryptocurrency wallet dashboard
- 💸 Send cryptocurrency to other users
- 📥 Receive cryptocurrency
- 📊 View wallet balance
- 📜 Transaction history
- 🛡️ Session-based authentication
- 📱 Responsive web interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/tejaswinichavan30/cryptocurrency-wallet.git
```

### Navigate to the project

```bash
cd cryptocurrency-wallet
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
